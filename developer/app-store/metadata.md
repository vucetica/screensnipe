## Description (max 4000 characters)
```
Screen Snipe is a lightweight, native macOS app for capturing your screen, annotating with precision, and organizing everything in a local library. All features are free, with no in-app purchases.

CAPTURE
• Region selection — click and drag to capture any area
• Full screen — capture your entire display instantly
• Window picker — click any window to capture it
• Configurable keyboard shortcuts with system-wide hotkeys

RECORD
• Record full screen, a region, or a specific window
• Pause and resume recordings
• System audio and microphone capture
• Visual countdown and recording border indicator

ANNOTATE
• Arrow, line, and shape tools
• Text annotations with customizable font and size
• Highlighter and blur tools for emphasis and redaction
• Crop to refine your capture
• Full undo/redo support

ORGANIZE
• Automatic local library — captures saved to a folder you choose
• Browse and manage all captures in one place
• Persistent annotations saved alongside each capture

EXPORT
• Copy to clipboard
• Save to file
• System share sheet

PRIVACY FIRST
• No data collection, no analytics, no network access
• Everything stays on your Mac

Requires macOS 14 or later. Screen recording permission is required.

Privacy Policy: https://screensnipe.app/privacy
```
